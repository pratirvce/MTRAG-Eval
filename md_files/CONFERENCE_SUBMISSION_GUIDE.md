## ⚠️ Important Notes

1. **One Submission Per Task**: MTRAGEval allows only one run per task per team. If you submit multiple, only the last one will be evaluated.

2. **System Description Papers**: Mandatory for inclusion in official ranking. Papers must describe your approach.

3. **Evaluation Data**: Will be provided to registered participants at the start of evaluation phase (Jan 12, 2026).

4. **Metadata Not Provided**: During evaluation, metadata (question type, answerability, multi-turn type) will NOT be provided. Only corpus domain will be given.

5. **SemEval vs. Main Conference**: 
   - SemEval is a workshop (Tier 2)
   - But papers are in ACL Anthology (high visibility)
   - Can extend to Tier 1 conferences later
